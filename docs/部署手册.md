# 部署手册 · 实验室设备预约系统（Gitee Pages）

> 写给下届同学：跟着本手册，30 分钟内可把纯前端项目免费上线为公网可访问的网址。
> 维护人：吴辰枫

## 1. 路线选择
本项目是**纯前端静态站点**（无后端、无数据库），对照附录 B 选「静态托管」路线：

| 候选 | 结论 |
| --- | --- |
| Gitee Pages | ✅ 采用。与代码同平台、国内访问快、免费 |
| 学生云服务器 | 本项目无后端，不必购买 |
| EdgeOne Pages 等 | 备选，需额外注册云账号 |

## 2. 前置条件
- 已在 Gitee 建好**公开**仓库，并把代码 push 到 `master` 分支
- 账号已完成**实名认证**（Gitee Pages 强制要求）
- 站点入口 `index.html` 位于仓库根目录（本项目满足）

## 3. 开启 Gitee Pages（网页操作）
1. 浏览器打开仓库主页：`https://gitee.com/huanz-007/project1`
2. 顶部菜单选择 **「服务」→「Gitee Pages」**（若未见入口，在 `https://gitee.com/help/articles/4136` 文档页按引导开通）
3. 部署参数：
   - **部署分支**：`master`
   - **部署目录**：留空（即根目录，因 `index.html` 在根目录）
   - 强制 HTTPS：勾选
4. 点击 **「启动」**，等待约 10~30 秒，页面显示访问地址：

   **🌐 线上地址：`https://huanz-007.gitee.io/project1`**

5. 用手机（关闭 Wi-Fi 用 4G/5G）打开该地址，确认能看到设备卡片和预置预约数据，即为公网可访问。

## 4. 更新部署（每次改完代码）
Gitee Pages 不会随 push 自动更新，需手动重新部署：
1. 本地 `git push` 后，再次进入「服务 → Gitee Pages」
2. 点击 **「更新」**（分支、目录保持不变），等待完成即生效
3. 若页面未变化，浏览器强制刷新（Ctrl+F5）清缓存

## 5. 验证清单
- [ ] 公网地址用手机移动网络可打开（非仅本机可见）
- [ ] 能看到设备卡片与预置预约（真实数据）
- [ ] 能提交预约、冲突时被拒绝
- [ ] 数据看板三张图表正常显示
- [ ] 地址为 HTTPS

## 6. 常见问题（FAQ）
| 现象 | 原因 / 处理 |
| --- | --- |
| 线上打开 404 | 部署目录或分支选错；确认 `index.html` 在所选分支根目录 |
| 页面样式丢失 / 图表空白 | 资源写成了绝对路径；本项目已全部用相对路径，检查是否被改动 |
| 手机能开电脑不能开（或反之） | 浏览器缓存，强制刷新；Gitee Pages 有几分钟 CDN 延迟 |
| 找不到 Pages 入口 | 账号未实名，先去设置完成实名认证 |
| 更新后内容没变 | 「Gitee Pages」页点「更新」，并 Ctrl+F5 强刷 |

## 7. 备选：本地 / 局域网临时预览
```bash
# 仓库根目录
python -m http.server 8000
# 本机 http://localhost:8000；同局域网用 http://本机IP:8000
```
