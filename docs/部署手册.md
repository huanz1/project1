# 部署手册 · 实验室设备预约系统（GitHub Pages）

> 写给下届同学：跟着本手册，30 分钟内可把纯前端项目免费上线为公网可访问的网址。
> 维护人：吴辰枫

## 1. 路线选择与变更说明
本项目是**纯前端静态站点**（无后端、无数据库），对照附录 B 走「静态托管」路线。

- 最初计划 **Gitee Pages**，但**该服务已于 2024 年因不可抗原因下线，官方答复暂无恢复计划**（仓库「服务」菜单里已找不到入口，旧教程均失效）。
- 故改用 **GitHub Pages**：免费、push 后自动部署、稳定。

| 候选 | 结论 |
| --- | --- |
| Gitee Pages | ❌ 已下线（2024） |
| **GitHub Pages** | ✅ 采用 |
| EdgeOne Pages | 备选（国内访问更快，但需腾讯云实名） |
| 学生云服务器 | 本项目无后端，不必购买 |

> 提示：`*.github.io` 在国内手机网络下偶尔偏慢或不稳定，若现场打不开，可换网络/挂代理，或改用 EdgeOne Pages。

## 2. 前置条件
- 一个 GitHub 账号
- 建一个**公开（Public）**仓库，把代码推到默认分支（本项目为 `main`）
- 站点入口 `index.html` 位于仓库根目录（本项目满足）

## 3. 开启 GitHub Pages
1. 打开仓库：`https://github.com/huanz1/project1`
2. 进入 **Settings（设置）→ Pages**
3. **Build and deployment → Source**：选择 **Deploy from a branch**
4. **Branch**：选择 `main` 分支、目录 `/(root)`，点击 **Save**
5. 等待 1~2 分钟，页面顶部出现线上地址：

   **🌐 线上地址：`https://huanz1.github.io/project1/`**

6. 用手机打开该地址，确认能看到设备卡片与预置预约数据，即为公网可访问。

> 现代 GitHub 也可用 GitHub Actions 自动部署；本项目结构简单，用「Deploy from a branch」即可。

## 4. 更新部署
push 到 `main` 后 GitHub Pages **自动重新部署**（无需手动点更新），1~2 分钟生效；页面未变化就强制刷新（Ctrl+F5）清缓存。

## 5. 验证清单
- [ ] 公网地址用手机网络可打开（非仅本机可见）
- [ ] 能看到设备卡片与预置预约（真实数据）
- [ ] 能提交预约、冲突时被拒绝
- [ ] 数据看板三张图表正常显示
- [ ] 地址为 HTTPS（GitHub Pages 默认开启）

## 6. 常见问题（FAQ）
| 现象 | 原因 / 处理 |
| --- | --- |
| 打开 404 | 刚部署需等待 1~2 分钟；确认分支、目录选择正确，`index.html` 在根目录 |
| 样式丢失 / 图表空白 | 资源写成了绝对路径；本项目全部用相对路径，检查是否被改动 |
| 国内手机打不开/很慢 | github.io 网络不稳定，换网络或挂代理；备选 EdgeOne Pages |
| 更新后内容没变 | 等待 1~2 分钟自动部署，再 Ctrl+F5 强刷 |

## 8. AI 代理的部署（第 7 天新增，AI 功能依赖）

GitHub Pages 只能托管静态文件，**跑不了 AI 代理**（Key 更不能进前端）。三种用法按场景选：

| 场景 | 做法 | AI 可用性 |
| --- | --- | --- |
| 本机演示/开发 | `AI_API_KEY=sk-xxx node server/server.js` → http://localhost:3000 | ✅（推荐答辩现场用） |
| 学生云服务器 | 把仓库推上去，`node server/server.js` + pm2/systemd 常驻；安全组放行端口；域名反代 | ✅（公网可访问） |
| 纯静态托管（GitHub Pages） | 无 | ❌ 页面明确提示“AI 不可用及原因”，其余功能正常 |

### 8.1 申请 Key（任选其一，均有免费额度）
1. **火山引擎方舟**：console.volcengine.com → 开通方舟 → 创建推理接入点 → API Key（默认 `AI_API_BASE=https://ark.cn-beijing.volces.com/api/v3`，模型填接入点 ID 或 `doubao-pro-32k`）。
2. **阿里云百炼**：bailian.console.aliyun.com → API-KEY（`AI_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1`）。
3. **硅基流动**：siliconflow.cn → API Key（`AI_API_BASE=https://api.siliconflow.cn/v1`）。

### 8.2 启动与自检
```bash
AI_API_KEY=你的Key node server/server.js
curl http://localhost:3000/api/health     # 期望 {"ok":true,"ai":{"configured":true,...}}
```
月成本估算见 `docs/技术方案.md` §6.3（当前用量级 ≈ ¥0.4/月，免费额度可覆盖）。

### 8.3 安全清单
- [ ] Key 只出现在环境变量/服务器本地，**没有**写进任何提交（`git log -p | grep -i sk-` 自查）；
- [ ] 前端代码、仓库、Issue 中无 Key；
- [ ] 一旦怀疑泄露：平台侧立即吊销重发，旧 Key 按已泄露处理；
- [ ] 服务器部署时端口不对公网裸暴露密钥（密钥本就不经过前端，无此风险，仅提示）。
