## 坑在哪
1. **看板在隐藏 Tab 里初始化，图表不显示。** 最初 AI 在页面加载时就 `echarts.init`，但看板页默认 `display:none`，容器宽高为 0。改成「切换到看板 Tab 时才懒初始化」后解决。
2. **ECharts 容器没高度。** 不给容器显式高度，图表渲染成 0 高。固定 `height:280px` 后正常。
3. **最初用 CDN 引 ECharts**，考虑到机房网络抖动会白屏，改为下载到本地 `vendor/`，线上更稳。
4. 日期不设下界会预约到历史日期，补了 `min=今天`。

## 对话档案（提问 → 返工 → 通过）
**【提问】** 「把 ECharts 接进预约系统，做一个各设备预约次数的柱状图。」
**【AI 初稿】** 页面加载即 `echarts.init` 并 `setOption`。
**【返工】** 发现切到看板 Tab 时图表空白（容器初始为隐藏状态、宽高为 0）。反馈：「图表在隐藏 Tab 里，打开是空白，要切到看板时才初始化。」
**【AI 修正】** 封装 `ensureChart(domId)`：首次切到看板时才 `init`，并监听 `window resize` 重绘。
**【通过】** 切换到看板，柱状图按设备正确渲染，缩放窗口不错位；与 localStorage 预约数核对一致。
